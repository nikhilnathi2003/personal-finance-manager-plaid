# Personal Finance Manager with Plaid

A private-first finance manager with a Node.js backend, React Native mobile app, Supabase auth/data storage, Plaid bank linking, budgets, goals, trends, and AI-powered insights.

## Highlights

- Plaid Link integration for read-only account and transaction access
- Supabase authentication and database schema
- Budgets, savings goals, recurring subscription detection, trends, and net-worth views
- Gemini-powered insights endpoint with rate limiting
- React Native / Expo mobile app

## Security

This public repository intentionally excludes real `.env` files, Plaid secrets, Supabase service-role keys, Gemini keys, `node_modules`, and local data files. Use `.env.example` files and sandbox keys when testing.
